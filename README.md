# Nuclear Engineering Science Codes

A collection of Python codes and Jupyter notebooks for nuclear engineering
calculations, with a focus on neutron physics, reactor physics and nuclear fuels.
They are written as teaching material.

## 📚 Codes

| Folder | Description |
| --- | --- |
| [Neutron_Reproduction_Factor](Neutron_Reproduction_Factor/) | Neutron reproduction factor η of the uranium and plutonium isotopes from JEFF-4.0 (2025) nuclear data: η(E), spectrum-averaged ⟨η⟩ with 1σ errors, the four-factor formula and reactivity. Written for a reactor-operator course. |

Each folder is self-contained, with its own README, `requirements.txt`, data and
rendered documents (HTML, PDF, DOCX).

## 🚀 Getting Started

### Prerequisites

- Python 3.12 or higher
- Python, Jupyter and Quarto extensions in VS Code

### Installation

```bash
git clone https://github.com/tjvanrooyen/Nuclear-Engineering-Science-Codes.git
cd Nuclear-Engineering-Science-Codes/Neutron_Reproduction_Factor
pip install -r requirements.txt
```

Then follow the README in the code's folder.
