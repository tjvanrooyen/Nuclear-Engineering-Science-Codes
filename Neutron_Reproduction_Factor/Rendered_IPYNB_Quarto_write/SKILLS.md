The Quarto renderings of the IPYNB notebook must be placed here in this folder.

Formats:

1. html; single file with embedded graphs.
2. pdf, rendered using typst.
3. docx. Body text of docx must be 16-point font, tables must be 12-point font and code sections must be mono-spaced 10-point font, preferably the Consolas typeface.  Code sections must have line spacing = singular and paragraph alignment = left.

The docx must be rendered by using the docx rendering template in folder “Rendering_Template_read”.
